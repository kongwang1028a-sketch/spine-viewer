Spine 多組檢視器 3.8

圖層 （下面的畫在上面，同 Cocos 節點順序）

    把 .skel / .json + .atlas + .png 拖進畫面（可一次多組、可整個資料夾）。單獨的 PNG 會變成圖片圖層（用來當靜態 Symbol）。字型檔（.ttf/.otf）或 Cocos 點陣字（.fnt + .png）會加進掛點字型。
    放開以匯入
    — 0.000 / 0.000 s

    使用說明

    • 匯入：拖檔案或資料夾進畫面。同名 X.skel（或 X.json）＋ X.atlas ＋ atlas 裡列的 PNG 會組成一組 Spine；.meta 自動略過。可一次匯入多組，全部同時播放。
    • 座標：原點在畫面中央、Y 朝上，跟 Cocos 節點座標一樣；X / Y / 縮放 可直接填 Cocos Inspector 的數值。底下狀態列顯示游標座標。
    • 移動圖層：在畫面上直接點圖層就會選取，拖曳改 X / Y（多選時一起移動，選取的圖層有藍色虛線框）。重疊時優先選已選取的、其次範圍最小的；點不到想要的就先在左邊清單選它，或用 Shift＋拖曳（不管點在哪都拖選取的圖層）。Ctrl＋點 加選 / 取消。
    • 鏡頭：滾輪縮放；拖空白處、中鍵 或 Alt＋拖曳 平移。
    • 自動對位：把企劃 / 美術的 Layout 圖（PNG）匯入成圖片圖層，擺成跟設計框對齊（縮放 1，1 px = 1 單位）。選要對的元件 → 屬性「自動對位」→「🎯 對位這個圖層」（多選時可一次對全部），會用元件目前這一格的畫面在 Layout 圖上、目前位置 ±搜尋範圍內找最像的地方，改 X / Y（跟隨中的改偏移）；勾「也找縮放」會在 0.85～1.15 倍之間一起找。結果顯示相似度，低於 0.6 代表可能認錯；按「↶ 還原」回到對位前。小訣竅：先停在跟 Layout 同一格、先大致拖到附近；Layout 有被擋住或元件大多是半透明光暈時比較不準，對完切「疊圖」確認。
    • 跟隨（搭配播放）：在圖層屬性選「跟隨」另一組 Spine，它會每幀對齊對方第 0 軌的動畫名與播放時間（對方播什麼它就播什麼，沒有同名動畫就播空動畫），位置也跟著對方。適合「本體一組、特效 / 數字另一組，兩組動畫名相同、要同步播」的情況，例如特效層 Hero_Fx 跟著本體 Hero。
    • 掛數字：「骨骼 / 掛點」區選骨頭 →「＋ 掛數字」，文字會跟著骨頭位置（可選是否跟旋轉、縮放），等同 Cocos 的 socket 節點。勾「顯示骨骼」後可直接在畫面上點骨頭來選。
    • 定位骨頭：像飛行軌跡、收集拖尾這種「程式在執行期把某根骨頭（例如 End）擺到目標」的動畫，選骨頭 →「📌 定位這根骨頭」，再拖畫面上的粉紅準心或填 X / Y。座標是這組 Spine 節點的本地座標（＝遊戲裡 convertToNodeSpaceAR 的結果），每幀蓋掉動畫的位置，子骨頭和 IK 會跟著重算。設定依骨架名稱記住。
    • 數字的文字框與對齊：掛點可設 Overflow、寬 / 高、橫向 / 直向對齊、行高、錨點，數值同 Cocos 的 Label 與 UITransform，可以直接照 Inspector 填。NONE：文字框就是文字大小，位數變多時依錨點往外長（錨點 X = 0 往右長、1 往左長）；CLAMP：用設定的寬高，超出裁掉；SHRINK：放不下就自動縮小。勾「顯示文字框」會畫出框線與錨點。
    • 字型：拖 .ttf / .otf / .woff，或 Cocos 點陣字 X.fnt ＋ 它的 PNG（BMFont 文字格式），掛點「字型」就能選（點陣字顯示為 [BMFont] X）。點陣字的字級換算同 Cocos（字級 ÷ 原始字級），顏色是乘色，可調字距（Spacing X）。字型不會記住，重新整理後要再匯入。
    • 淡入 / 淡出：圖層屬性「淡入 / 淡出」設延遲、時長、起始透明度、淡出開始時間與緩動（名稱同 cc.tween easing），等同 Cocos 對 UIOpacity 做 tween，掛數字會一起淡。計時可選「全域」（按「全部從頭」/ R 歸零）或「某組 Spine 目前動畫的時間」（例如背景跟著轉場動畫的時間淡入，轉場換動畫或重播就重來）。逐格、暫停、全域速度都有效。
    • mix（動畫切換混合）：「動畫」區的「預設 mix」＝ defaultMix；「＋ 動畫配對 mix」指定「從 A 切到 B」的秒數 ＝ sp.Skeleton.setMix('A', 'B', 秒)，按該列的 ▶ 會播一次 A 再接 B 看效果，也可以直接在動畫清單依序點。播放順序每一段的 mix 欄有填就優先（＝ setAnimation 後改 mixDuration）。多軌的 mix 是那一軌進場 / 關掉的漸變秒數。
    • 多軌播放：Spine 圖層的「多軌播放」→「＋ 加一軌」，選第幾軌、動畫、循環、權重（TrackEntry.alpha）、速度、延遲、疊加（MixBlend.add）。第 0 軌是上面的動畫 / 播放順序，軌號大的蓋在上面，等同 Cocos skeleton.setAnimation(1, 'Blink', true)。適合測「本體 Idle ＋ 表情 / 光效另一軌」這種組合。R 全部從頭、逐格、拖時間軸都會一起動；設定依骨架名稱記住。
    • 播放順序：按「⏺ 錄製」後依序點動畫（例如 Start → Loop → End），停止錄製時會記下每段播了幾次；也可以手動編輯。次數 0 = 無限循環，直到按「⏭ 下一段」（N 鍵）。設定依骨架名稱自動記在瀏覽器裡。
    • 靜 / 動態：圖層角色設「靜態」或「動態」，上方切換 全部 / 靜態 / 動態 / 疊圖 / 閃爍（S 鍵在靜態↔動態間切）。靜態可以是匯入的 PNG，或把 Spine 勾「凍結於時間」當靜態張。疊圖時靜態圖層半透明畫在最上面，方便對位置；閃爍適合抓顏色差。
    • 顏色對不上先查 PMA：Cocos 的 sp.Skeleton.premultipliedAlpha 對應本工具「PMA 混色」，PNG 匯入設定的 premultiplyAlpha 對應「貼圖預乘」，兩邊要一致才會跟遊戲內一樣。
    • 快捷鍵：空白 播放/暫停、R 全部從頭、← → 逐格、S 靜/動切換、N 下一段、B 顯示骨骼、Delete 刪除選取的圖層。
    • 圖層多選：Shift＋點擊 選取一段範圍、Ctrl＋點擊 加選 / 取消；選取後可按「刪除選取」或 Delete 一次移除，勾選其中一項的顯示框會整批一起切換。
    • Skin：圖層屬性「動畫」區的 Skin 下拉選要用的 Skin（同 sp.Skeleton.setSkin），◀ ▶ 可以一個一個切過去看。骨架有三個以上的 Skin 時會多一個「疊加其他 Skin」，勾選的會疊在主要的 Skin 上（同 runtime 的 new Skin() + addSkin()），給部位拆成好幾個 Skin 的換裝骨架用。選的 Skin 會記住。
    • 圖層排序：在左邊清單直接拖曳圖層到想要的位置（藍線是放下後的位置），拖多選中的一項會整批一起搬；也可以用 ▲ ▼ 一格一格移。清單越下面畫在越上層，順序會記住。
    • Runtime 是 spine-ts 3.8（Cocos Creator 3.8 內建的 Spine 版本）；4.x 的檔案讀不了，會顯示檔案版本。
